# Смета за 5 минут

Веб-приложение для быстрого составления сметы или коммерческого предложения и сохранения результата в PDF.

Для кого:
- предприниматели — подготовить коммерческое предложение клиенту;
- офисные сотрудники — составить смету закупки или расчёт расходов для руководителя.

## Файлы приложения

Планируемые файлы (пока не созданы):
- `index.html` — структура страницы, поля ввода и кнопки;
- `styles.css` — оформление, удобные размеры элементов и адаптация для телефона;
- `script.js` — расчёт сумм и логика сохранения в PDF.

## Как открыть

После создания файлов приложения дважды щёлкните по `index.html`. Страница откроется в браузере без установки дополнительных программ.

## Как проверить

После реализации расчёта добавьте две позиции:
- количество 2, цена 15 000 ₸ — сумма 30 000 ₸;
- количество 1, цена 8 000 ₸ — сумма 8 000 ₸.

Итог должен быть **38 000 ₸**: 2 × 15 000 + 1 × 8 000 = 38 000 ₸.
